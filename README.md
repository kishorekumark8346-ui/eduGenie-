# EduGenie : Smart Learning Assistant Using Google Gemini

## Project Description

EduGenie is a lightweight AI-powered educational assistant that uses Google Gemini to help students learn easily and effectively.

## Features

- Smart Question & Answer
- Simple Explanations
- Quiz Generation
- Personalized Learning Path
- Text Summarization

## Technologies Used

- Python
- FastAPI
- Google Gemini AI
- HTML
- CSS

- Python 3.10+
